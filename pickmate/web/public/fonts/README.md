# PickMate fonts

Self-hosted Latin WOFF2 files from Google Fonts, downloaded 2026-09-08. The English MVP loads these local assets without a Google Fonts runtime request.

- **Barlow Condensed**, Google Fonts v13, weights 600 and 700: [family](https://fonts.google.com/specimen/Barlow+Condensed), [source](https://github.com/google/fonts/tree/main/ofl/barlowcondensed), license in `Barlow-Condensed-OFL.txt`.
- **Public Sans**, Google Fonts v21, variable weights 400–700: [family](https://fonts.google.com/specimen/Public+Sans), [source](https://github.com/google/fonts/tree/main/ofl/publicsans), license in `Public-Sans-OFL.txt`.

Both families use the SIL Open Font License 1.1. The font files are unmodified Google Fonts Latin subsets. Other scripts use the system fallback and are outside the English acceptance scope.
